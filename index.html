The Summer Lightning Broke (a Little)

Every Lightning implementation shipped security fixes in the same ten weeks. When Core Lightning asked operators to go offline, 38% of channels toward CLN nodes went disabled overnight, and about a third of the nodes that went dark were still dark five weeks later. The big force-close spikes turned out to be single operators. Measured from daily gossip and every on-chain close.
